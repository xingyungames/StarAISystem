# ③ 发言门

> 代码：`src/StarGameAI/Pipeline/Gate.cs`
> 配置：`config/gate.json`
> 页面：后台 `#gate`（主动说话）

一句话：**这一句，我该不该开口。**

---

## 分四段

```
① 协议硬判定    真 @ 我 / 私聊 → 直接回（不占主动额度）
② 内容判定      有没有可判断的文字（纯表情/图片 → 静默）
③ 模型判定      {addressed, score, intent, need_think}
④ 主动侧闸门    addressed=true → 按被动回；false → 冷却 → 额度 → 阈值
```

---

## ① 协议硬判定

只有一种情况可以零成本直接放行：**OneBot 的 `at` 段指向 self_id**，或者这是私聊。

这是唯一还保留的硬判定，因为 at 段是协议层给的，不是猜的。

## ② 内容判定：只问"有没有字"

```
抹掉 [图片] / [表情] / [卡片] / [语音] 这类协议占位符
→ 还有可判断的文字吗？没有就静默
```

**刻意不再用噪声词表。** 原来那套是"抹掉噪声词后剩不下两个字就算灌水"，
结果把「星璃」这种两字点名判成了灌水——最纯粹的"在叫我"，连模型都没送到。

灌水与否交给后面的模型判断，它看得见上文，比词表准。

## ③ 模型判定：阈值完全交给模型

```json
{ "addressed": false, "score": 0-100,
  "reason": "≤20字", "intent": "answer|add|ignore", "need_think": false }
```

payload 里给模型四样东西：

| 内容 | 为什么 |
|---|---|
| **自我描述放在最前面**（我叫什么 + 人设身份首句） | 放后面模型会跳过，实测出现过"我不是星璃"这种自述 |
| 最近 6 条对话 | 才知道"别人是不是在互相聊" |
| 群里正在被反复说的话 | 接梗时机 |
| `门槛 X/100` | 让它按同一个刻度打分，而不是各说各的 |

再补一条反误判线索：**消息里 `@` 了别人时，明确告诉它"这条 @ 的是别人，不是在 @ 我"**。

### `addressed` 是这一层最重要的输出

它区分两件本质不同的事：

| `addressed` | 含义 | 处理 |
|---|---|---|
| `true` | 这句话是在对我说 | 按被动回复，**不看阈值**、不占主动额度 |
| `false` | 大家在聊，我可以插 | 这才是主动插话，要过冷却、额度、阈值 |

名字只出现在正文中间（别人在议论我）、或者这句话是在教别人怎么 @ 我——
这些情况规则写不完，但模型连着上文一眼就能看出来。

### 判定失败默认静默

网络/解析失败时**不说话**。

原来是保守放行（`Speak=true`），但那是按"宁可多说"设计的；实盘下来代价反了：
主动插嘴说错话，比沉默一次糟得多。想退回旧行为设 `fail_open_on_error: true`。

## ④ 主动侧的三个闸

只有 `addressed=false` 才走：

```
冷却（cooldown_seconds）→ 每小时额度 → 每日额度 → 阈值（ambient_threshold）
```

注意 `addressed=false` 的判定**发生在花了模型调用之后**——因为得先知道"是不是在跟我说话"。
成本闸门因此是 `max_llm_calls_per_day`，不是抽样。抽样已经去掉：抽样是拿准确率换钱，
而这里本来就该由模型逐条判断。

---

## 为什么整层没有词表

`gate.json` 里曾经有 `noise_words` 和 `direct_hints`，现在都废弃了（键还在，不再生效）。两个方向的错：

| 词表 | 错在哪 |
|---|---|
| `noise_words`（灌水词） | 「星璃」两个字被判成灌水，直接叫名字反而静默 |
| `direct_hints`（吗/呢/？/是不是） | 群里任何一句带「吗」的话都触发 85 分硬答，完全绕过上下文判定 |

而且这类错是**修不完的**——你补一个词，就漏另一个。

## 配置（`config/gate.json`）

| 参数 | 作用 |
|---|---|
| `enabled` | 总开关。关掉后所有消息按普通回复处理 |
| `ambient_threshold` | 主动插话门槛（写进 prompt，模型按这个刻度打分） |
| `cooldown_seconds` | 两次主动发言的最小间隔 |
| `daily_budget` | 每天主动插话上限（防刷屏被风控） |
| `max_llm_calls_per_day` | 判定调用上限（真正的成本闸门） |
| `bot_names` | 我自己叫什么。**为空会自动从人设里捞**，但仍建议显式填 |
| `fail_open_on_error` | 判定失败时是否放行（默认 false） |
| `event_boost` | 群里的复读话术，只作上下文，不折算成分数 |

`groups` 可以按群覆盖阈值、冷却、预算。

## 后台怎么调

「主动说话」页最上面那行是**判定模型看到的「我是谁」**。
叫名字不认人的时候，第一件事就是看这一行——只要写着「你叫「星璃」」，这一层就不会犯那个毛病。

下面的**门控沙盒**可以粘一段话进去，返回完整判定链路：哪一层拦下的、分数多少、
模型认为是不是在跟我说话。调阈值不用发真消息，也不占额度。

---

## 常见故障

| 现象 | 原因 |
|---|---|
| 叫它名字不理 | `bot_names` 空且人设【身份】里没有「我叫 X」 |
| 抢答别人的话 | `addressed` 判错；或 `fail_open_on_error=true` |
| 该静默时在说话 | `ambient_threshold` 过低 |
| 判定次数用尽后整天静默 | `max_llm_calls_per_day` 太小（每条消息都要判定） |
| 沙盒里显示"判定失败" | 模型 Key 或网络问题 |
