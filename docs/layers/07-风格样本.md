# ⑥ 风格样本

> 代码：`src/StarGameAI/Core/StyleSamples.cs`
> 配置：`config/style.json`
> 页面：后台 `#style`（风格样本）

一句话：**碎片记的是摘要，摘要丢掉的正是语气、停顿、动作——而那也是"我"。**

---

## 为什么需要这一层

私聊里建立起来的说话样子，长这样：

```
（沉默了一会儿）你想听的话，我可以叫一声。但这不是我平时说话的样子。
（说完就别过头）
（没接话，耳朵有点热）
```

而记忆里存下来的是：`对方希望我说简单点、可爱些，用括号表达情感和动作，偶尔用就好`。

**摘要把动作、停顿、留白全丢了。** 所以一进群就显得像换了个人——
不是它在演另一个人，是它手上根本没有"我平时怎么说话"的样本。

---

## 数据结构

```jsonc
{
  "id": "s1234abcd",
  "ts": 0,
  "scope": "private:10001",
  "source": "manual | model",
  "verdict": "approved | rejected | pending",
  "text": "（没接话，耳朵有点热）",
  "self_score": 0-100,      // 模型自评「像不像我平时的样子」
  "weight": 0.0-1.0,
  "updated_at": 0
}
```

存放在 `data/style/samples.json`，上限 200 条。

---

## 准入：不确定性驱动（ab 混合）

> 参考了**卡尔曼滤波**——但没有线性高斯状态空间，也不做协方差递推
> 但抄了同一个结构：**观测权重 ∝ 1/不确定度**
> 先验不确定 → 更信观测；先验收敛 → 更信先验

翻译成这里：样本少、彼此不像的时候只听人工；样本多了、越来越像之后，放开模型自评自动入库。

### 三个量

```
coverage     = min(1, 已批准数 / target_samples)
consistency  = 风格特征向量离散度的补数
uncertainty  = 1 - coverage × (0.5 + 0.5 × consistency)
```

`coverage` 不足会给不确定度一个下限（至少 0.5），所以样本再像，数量不够也进不了自适应。

### 三种模式

| 模式 | 不确定度 | 模型自评的样本怎么处理 |
|---|---|---|
| `manual` | > 0.65 | 一律挂 `pending`，等人批准 |
| `assisted` | 0.35 ~ 0.65 | 自评 ≥ 70 才收，权重 × `model_weight`（默认 0.4） |
| `adaptive` | < 0.35 | 自评 ≥ 55 直接收 |

**人的判断永远压得住它**：人工样本权重恒为 1.0，模型样本最高 0.4。

实测迁移：

| 样本 | 模式 | 不确定度 | 覆盖度 | 一致性 |
|---|---|---|---|---|
| 0 条 | manual | 1.000 | 0 | 0 |
| 3 条（同风格） | manual | 0.697 | 0.375 | 0.614 |
| 8 条（同风格） | **adaptive** | 0.152 | 1.0 | 0.697 |
| 9 条（掺一条公文风） | adaptive | 0.255 | 1.0 | **0.49 ↓** |

掺一条「综上所述，该方案在工程实施上具备可行性」之后一致性立刻掉——
这就是"数据没收敛就不敢放权"。

## 一致性为什么不能用文本相似度

第一版拿 `TextSim`（字符二元组 Jaccard）算，结果 8 条明显同语气的样本只给出
`consistency = 0.002`：

```
（沉默了一会儿）你想听的话，我可以叫一声。
（没接话，耳朵有点热）
```

这两句字面上几乎没有共同二元组，但谁看都知道是同一个人的话。

**这和「整句相似度抓不住同一件事」是同一个教训：风格不是词汇重叠。**

### 改成结构特征向量（6 维，每维 0~1）

| 维度 | 含义 |
|---|---|
| 开口是不是括号动作 | `（…）` / `(…)` 开头 |
| 动作占比 | 括号内字数 / 总字数（上限 0.6 归一） |
| 长度 | 字数 / 60 |
| 爱不爱用省略号 | 含 `…` 或 `...` |
| 爱不爱反问 | 含 `？` / `?` |
| 有没有第一人称 | 含「我」 |

`consistency = clamp(1 - 各维标准差的均值 / 0.35, 0, 1)`

看结构，不看词汇。

## 样本从哪来（ab 混合）

### (a) 人工喂

后台「风格样本」页输入一句话 → `POST /api/style` → 直接 `approved`，权重 1.0。

这是**种子**。刚开始必须靠人喂，因为这时候不确定度是 1.0，模型候选一律挂起。

### (b) 模型自评

**在睡眠巩固时**做，不在对话时做：

```
从私聊片段里挑出"我自己说过的话"（4~120 字，每片最多 8 条）
→ 让模型给每条打 0~100 分：「像不像一个人自然说出来的样子」
→ 交给 Propose()，按当前不确定度决定收不收
```

为什么放在巩固阶段：这是批处理，**不占用对话延迟**；而"像我吗"本来就是个慢问题。

---

## 注入

已批准样本按权重取前 `inject_top_n` 条，注入到系统提示：

```
【我平时说话的样子】（参照语气和动作，别照抄原句）
- （没接话，耳朵有点热）
- （把杯子往你那边推了推）
```

不确定度还没收敛时，额外加一句"这份样本还在收敛中，以人设为准"。

---

## 配置（`config/style.json`）

| 参数 | 默认 | 作用 |
|---|---|---|
| `enabled` | true | 是否注入 |
| `target_samples` | 8 | 覆盖度目标样本数 |
| `manual_above` | 0.65 | 不确定度高于此 → manual |
| `adaptive_below` | 0.35 | 不确定度低于此 → adaptive |
| `assisted_min_score` | 70 | assisted 模式的自评门槛 |
| `adaptive_min_score` | 55 | adaptive 模式的自评门槛 |
| `model_weight` | 0.4 | 模型样本权重上限（人工恒为 1.0） |
| `inject_top_n` | 4 | 每次注入几条 |

---

## 怎么用

1. 打开「风格样本」页，先喂 8 条左右你觉得"就是她"的话
2. 看不确定度条往下走、模式从 manual 变成 adaptive
3. 之后巩固时模型自评够高的样本会自动进来
4. 不像的样本随时否决——**人工改判权重立即变成 0 或 1.0**

---

## 常见故障

| 现象 | 原因 |
|---|---|
| 一直停在 manual | 样本数不够 `target_samples`，或彼此差别太大（consistency 低） |
| 模型样本一直 pending | 不确定度还高，这是应有的行为 |
| 注入没效果 | `inject_top_n` 为 0 / 样本都是 `rejected` |
| 一致性很低 | 喂的样本风格不统一——先想清楚"她到底是哪种说话方式" |
