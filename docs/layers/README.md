# 分层解剖

这个项目不是"一个机器人"，而是十来个各管一件事的层。每层都有自己的输入、输出、
失效模式和取舍理由。这个目录按层拆开讲：**它做什么、分几段、每段凭什么、参数在哪、坏了什么样**。

完整的决策记录（含每次踩坑的时间线和数据）在 [`../P0-技术规格.md`](../P0-技术规格.md)，
这里只讲"这一层本身是怎么想的"。

## 三条贯穿全局的原则

读任何一层之前，先知道这三条，很多"为什么这么设计"就自动通了：

### 1. 判不了就静默

不确定的时候什么都不做，而不是猜一个。

体现在：发言门判定失败 → 静默；对话分块判不了 → `unresolved` 不硬塞；
思考层没动机 → 只允许产出权重，不许说话。
**允许说"我不知道"**，否则模型一定会编——实测崩到编出不存在的人名。

### 2. 权威性只能来自睡眠巩固

人格、画像、长期事实，只有巩固循环能写。对话过程中的即时反应**不改写自我**。

### 3. 每一条设计都要能看见数据

没有任何一层是靠"感觉调好的"。散布、归并、权重、一致性——所有数值都能在后台
看到、能被 `data/audit/` 里的记录复算。调参靠数据，不靠猜。
