# ④ 记忆层

> 代码：`src/StarGameAI/Memory/Store.cs`、`Pipeline/ChatPipeline.cs`（`RecallBlock`）
> 配置：`config/memory.json`
> 页面：后台 `#memory`（浅层）、`#deep`（深层）

一句话：**细节会过期，人不会。所以记忆分两层，浅的记细节，深的记人。**

---

## 两层结构

```
shallow/                      deep/
  group_<群号>.jsonl            person/<qq>.md      人物画像（长期，跨会话）
  private_<qq>.jsonl            group/<gid>.md      群画像（短期，会过期）
  ← 碎片：一条一条的细节         ← 画像：整段重写
  ← 7 天后进 archive/          ← 不会被"追加"，只会被"重写"
```

### 为什么必须分开

碎片是**流水**：越攒越多，含大量重复变体，掺着一次性话题。
画像是**结论**：稳定的、短的、可以整段重写的。

如果把两者混在一个存储里，就会出现"记忆越攒越多、但越来越不准"。

### `absorbed` 的语义

`absorbed = true` 表示**这一轮处理过了**，不是"已进入画像所以不再用来派生抽像"。

画像每次都是从**完整的碎片池**重新推导的。这点曾经搞错过一次：
把 `absorbed` 当过滤条件，结果画像只能看到新碎片，越来越窄。

## 召回：三档逐级升级

`RecallBlock` 决定这次注入哪些记忆。

### 第 1 档：本场景浅层碎片

打分公式：

```
0.55 × 相关度 + 0.20 × 权重 + 0.15 × 时间衰减 + 0.10 × 类型加成
```

- **相关度**：字符二元组覆盖率（中文不引分词器）
- **时间衰减**：`exp(-ageDays / 30)`
- **类型加成**：identity / fact 1.0，preference 0.9，event 0.8，capability 0.7
- 分数 ≥ 0.18 才注入

### 第 2 档：本场景捞不到 → 往上翻一层

```
· 这个人画像的后半段（前 500 字已注入过，这里补被截掉的部分）
· 你私下里记着他的事（跨场景私聊碎片，最多 4 条）
```

### 第 3 档：还不够 → 翻归档

`memory/archive/` 里那些早就被吸收、平时从不注入的老事，按关键词挑 3 条。

> 为什么需要升级：浅层碎片在新场景里经常是空的（新群、刚睡醒、没沉淀过）。
> 空了就一无所知地硬聊，人设会明显飘。

## 注入的五个块

`BuildSystem` 拼出来的系统提示里，和记忆/身份相关的是这样几段：

| 块 | 内容 | 来源 |
|---|---|---|
| 【自我】 | 人设五个段落 | `data/persona/System Prompt.md` |
| 【关于这个人】 | 人物画像 | `deep/person/<qq>.md` |
| 【这个群】 | 群画像 | `deep/group/<gid>.md` |
| 【约定了什么】 | 所有跨场景的 commitment，带生效范围 | 记忆层（见 [身份与约定](08-身份与约定.md)） |
| 【我最近说过的话】 | 跨会话，按时间倒序 | 聊天日志 |

### 占位符归属

`[图片]` / `[表情]` / `[语音]` 是 OneBot 拍平的副作用，最容易张冠李戴。
所以 prompt 里会显式写：

> 历史里 `[图片]`/`[表情]`/`[语音]` 这类占位符**标在谁名下就是谁发的**，
> 不要算到紧接着说话的人头上。

当前这条消息含占位符时，会再单独点一次"这是上面那位发的"。

### 跨场景桥：换个地方聊，别当第一次见

历史是**按 scope 分文件**存的。所以私聊里熟的两个人，一进群就互相变陌生人。

两处补救：

1. **碎片层**：群里说话时，把这个人的 `private:<qq>` 碎片捞几条过来
2. **原文层**：群里跟私聊熟人说话时，把他私聊里最近 4 句**原话**捞进来
   （`【你私下里跟他说过的话】（换个地方聊，别当第一次见）`）

碎片补的是"事实"，原文补的是"刚才聊到哪"。

## 睡眠期间

巩固期间（`SleepState.Sleeping`）原来是把记忆**整个丢掉**的。实测一次巩固 38 秒，
这段时间里所有回复都像刚认识的陌生人。

现在改成注入**瘦身版**：只带"这个人是谁 / 这个群是什么"两段轮廓（各 200~260 字），
不翻碎片、不做深层唤醒。

## 配置（`config/memory.json`）

| 参数 | 默认 | 作用 |
|---|---|---|
| `shallow_retention_days` | 7 | 碎片保留天数，过期进 archive |
| `person_half_life_days` | 90 | 人物画像衰减半衰期 |
| `group_half_life_hours` | 72 | 群画像衰减半衰期 |
| `person_profile_max_lines` | 40 | 人物画像行数上限 |
| `group_profile_max_lines` | 60 | 群画像行数上限 |
| `group_pattern_min_count` / `min_weight` | 2 / 0.05 | 群体模式入选门槛 |
| `group_pattern_expire_days` | 7 | 模式过期 |
| `max_objects_per_sleep` | 12 | 一次巩固最多更新几个对象 |
| `min_turns_to_update_person` | 2 | 至少几轮对话才更新人物画像 |

## 记忆类型

| kind | 含义 | 注意 |
|---|---|---|
| `identity` | 关于**我自己**的身份与自我认识 | 绝不能写成对方的（有硬校验，见下） |
| `fact` | 关于对方的客观事实 | **不要反复记**「对方叫星涵」这类 |
| `preference` | 偏好、期待、对我的要求 | |
| `event` | 发生过的事 | |
| `capability` | 明显做不到、缺少能力的需求 | 不进人物画像 |
| `commitment` | **约定与边界**，带生效范围 | 见 [身份与约定](08-身份与约定.md) |
| `quote` | 原话 | 风格样本走单独存储 |

### identity 的硬校验

中文「（你可以）叫我星涵」是歧义的：可以是"你给我起名叫星涵"，也可以是"你称呼我为星涵"。
蒸馏模型会把它读成前者，写出「我叫星涵」。

所以落库前有一道 `GuardIdentity`：断言「我叫 X」里的 X 必须和已确认的自我名
（人设【身份】+ `gate.bot_names`）一致，不一致就**降级成 fact 并归到说话人头上**。

这道校验的正则**刻意不匹配「我是 X」**——「我是星云游的一份子」是自我描述，
把「星云游的一份子」当名字去校验会误伤。

## 常见故障

| 现象 | 原因 |
|---|---|
| 换个群就不认识人 | 跨场景桥没生效 / 该人不算"可私聊对象" |
| 记忆说了但它不用 | 注入被截断（`max_context_chars`）、或分数没到 0.18 |
| 记忆越攒越乱 | 碎片没被吸收（巩固没跑）/ 事实类重复记录 |
| 它就是记不住某件事 | 该事实从没被抽出来（蒸馏漏了），不是召回的问题 |
| 群画像把自己写成群成员 | 巩固的群画像 prompt 已被修，旧画像要重跑一次巩固 |
